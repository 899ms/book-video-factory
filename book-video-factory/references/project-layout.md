# 项目结构

## 设计目标

- 一个工作区管理多个账号。
- 账号共享素材与单书产物分离。
- 工作区移动或复制后配置仍然有效。
- 中断后可从 `book.yaml` 恢复，而不是依赖聊天记录。

## 目录职责

```text
book-video-workspace/
├── workspace.yaml             # 工具能力和工作区默认项
├── .env.local                 # 本机密钥，不提交
├── .gitignore
└── accounts/
    └── <account-id>/
        ├── account.yaml       # 账号长期规则
        ├── production.csv     # 账号生产总览
        ├── shared/            # 该账号反复复用的素材
        ├── books/             # 每本书的完整生产档案
        └── exports/           # 待发布、已发布和归档成片
```

单书目录固定包含九个阶段：

| 目录 | 内容 |
|---|---|
| `01-research` | 来源、事实摘要、资料缺口 |
| `02-script` | 已确认和历史版本口播稿 |
| `03-storyboard` | 字幕分句、画面段落、提示词 |
| `04-images` | 背景图片及可选缩略图 |
| `05-audio` | 原始旁白、处理后旁白、BGM 混音 |
| `06-transcript` | 转录、字幕和时间点 |
| `07-render` | 按渲染器分组的视频工程 |
| `08-preview` | 低成本预览产物 |
| `09-output` | 正式成片和导出清单 |

## 命名规则

- 账号 ID：小写字母、数字和连字符，最长 63 个字符。
- 书籍目录：三位递增编号加安全书名，例如 `001-book-title`。
- 版本文件：使用 `-vN`，例如 `script-v2.md`、`mix-final-v3.wav`。
- 正式导出：先进入单书 `09-output`，再复制到账号 `exports/ready`。

## 可移动性

- `account.yaml` 中的素材路径以账号目录为基准。
- `book.yaml` 中的产物路径以单书目录为基准。
- 不使用软链接指向工作区外文件；需要复用时复制到 `shared/`。
- 禁止 `..`、盘符路径、UNC 路径和以根目录开头的路径。
- URL 只用于来源或服务地址，不得伪装成本地素材引用。

## 安全边界

- `.env.local` 必须列入 `.gitignore`。
- 账号密码不属于工作区配置。
- 用户素材不得在未确认时上传第三方服务。
- Skill 只把成片放到 `ready`，不自动发布。
